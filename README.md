## 📌 Project Overview

**LocalLead AI** is an AI-powered local business research, competitor intelligence, lead generation, and automated sales outreach engine designed specifically for **Virtual Agency, India**. 

The initial campaign scans and prospects the **Car Detailing, PPF (Paint Protection Film), and Ceramic Coating** market throughout **Delhi NCR**, cross-auditing verified studios across 12 major automotive clusters (Okhla, Lajpat Nagar, Mayapuri, Rohini, Dwarka, Vasant Kunj, Karol Bagh, Netaji Subhash Place / Pitampura, Janakpuri, Preet Vihar, Kirti Nagar, and Connaught Place).

---

## 🚀 Key Features & Dashboard Modules (10 Sections)

1. **Overview Dashboard**: High-level KPIs, pipeline stage funnels, locality spread, and top priority prospects.
2. **All Businesses**: Complete searchable and filterable database with Table View and Grid View toggles, min-rating, review count, and lead channel filters.
3. **Businesses Without Websites**: Target list for selling **Virtual Agency Studio Web Starter Packages (₹25,000–₹40,000)**. Highlights customer demand vs. competitor revenue leakage.
4. **Businesses With Websites**: Candidates for **Speed, CRO & Local SEO Retainers (₹18,000–₹28,000)**. Flags mobile speed bottlenecks (<60), missing WhatsApp widgets, and broken contact forms.
5. **High-Priority Leads**: Pre-screened prospects scoring **80–100** on the 100-point weighted rubric with complete score breakdown chips and 1-click outreach actions.
6. **Competitor Analysis (5 KM Radius)**: Side-by-side head-to-head comparison matrix comparing rating, reviews, website presence, and digital advantage against direct neighbors within 5 KM.
7. **Locality-Wise Analysis**: Breakdown across 12 Delhi automotive clusters showing saturation, average ratings, and website penetration rates.
8. **Website Audit Engine**: 13-point technical and conversion audit checklist (Mobile friendliness, HTTPS, Speed score, PPF pages, WhatsApp widget, Schema) with supporting evidence.
9. **Sales Pitch Generator**: Multi-channel outreach studio generating:
   - **WhatsApp Pitch in natural Hinglish** (with 1-click send button)
   - **Professional English Email Pitch**
   - **Instagram DM Pitch**
   - **5-Stage Cold Call Script for SDRs**
   - **48-Hour Follow-up Message**
   - **Audit Snapshot**
10. **Export Reports**: Multi-sheet **Excel (`.xlsx`)** report with all 7 sheets generated via SheetJS (`xlsx`), plus **CSV Export**.

## 📊 7-Sheet Excel Report Breakdown

The exported workbook `VirtualAgency_Delhi_CarDetailing_Prospects_2026.xlsx` contains:
- **Sheet 1: All Leads** — Complete master database of all verified studios.
- **Sheet 2: No Website** — Target list of studios without websites with package suggestions.
- **Sheet 3: Website Audit** — 13-point technical audit parameters for every studio.
- **Sheet 4: Competitors** — 5 KM head-to-head comparison pairings and digital advantages.
- **Sheet 5: High-Priority Leads** — Score 80–100 leads with personalized Hinglish WhatsApp pitches and calling scripts.
- **Sheet 6: Marketing Recommendations** — Implementation plans, ROI business cases, KPIs, and INR pricing.
- **Sheet 7: Research Sources** — Compliance verification notes, Google Maps directory references, and Virtual Agency credentials.

## 🛠️ Tech Stack & Setup

- **Frontend Framework:** React 19 + Vite

- **Icons:** Lucide React
- **Data Export:** SheetJS (`xlsx`)

### Local Installation:

```bash

git clone https://github.com/virtualagency1709/AI-Bot.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
